### 🍽️ Weave POS
**The restaurant point of sale that keeps cooking when the internet doesn't.**

Orders, kitchen display, order board, delivery, stock and shift close run on the PC the restaurant already has, with a cloud back office that keeps every branch in step within seconds.

- 📶 **100% offline:** every till has its own database; orders queue in an outbox and sync without duplicates
- ⚡ **Syncs in seconds:** price, recipe and role changes reach every paired till moments later
- 🏢 **Multi-branch** cloud admin portal

### 🖼️ Profile Photo Filter API
**Send a portrait and a filter number. Get back a finished, sticker-style profile picture.**

A self-hosted HTTP service that finds the person in a photo and builds artwork around their outline, face, hair and hands. Runs on a small server with **no paid AI services**.

- 🎨 **Fitted filters:** glasses, eye paint, hair lines and hand outlines generated per face
- 🔑 **API keys:** per-customer rate limits and revocation, salted-hash storage
- 📊 **Admin console:** analytics, live server load, filter upload, test bench
- 🔐 **Private by design:** photos processed in memory only, EXIF/GPS stripped
